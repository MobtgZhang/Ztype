# Ztype 语法参考

`.zt` 是纯文本标记语言：一行就是一个块，空行分隔段落。设计目标：**书写优先**——
不需要宏、不需要括号嵌套，日常排版用到的结构都能一行写完。

## 文档结构

```
---
title:  文档标题
author: 作者
date:   2026-01-01
lang:   zh
---

= 一级标题

正文段落。

:: figure
src: image.png
caption: 图题
---
正文内容
```

- 文件开头的 `---` 块是**元数据**（`key: value`），见 [layout.md](layout.md)。
- 其余每一行按行首字符判断块类型；段落收集到下一个空行或块起始行为止。

## 标题

`=` 到 `======` 表示 1–6 级标题，末尾可加 `[id]` 供交叉引用：

```
= 章标题 [ch1]
== 小节
=== 子小节
```

标题自动编号（`numbering: true` 时输出 `1`、`1.2`、`1.2.3`），并进入目录与 PDF 书签。
标题内不断词，且至少与后一行内容留在同一页。

## 行内语法

| 写法 | 含义 |
|------|------|
| `*粗体*` | 强调（粗体） |
| `_斜体_` | 强调（斜体） |
| `` `代码` `` | 行内代码 |
| `$x = y$` | 行内公式 |
| `[文字](url)` | 链接 |
| `[->id]` | 交叉引用（标题、图、表、公式） |
| `[^脚注内容]` | 脚注 |
| `[@key]` | 引文，指向 `:: bibliography` 中的条目 |
| `@(变量)` | 脚本变量求值 |
| `^上标^` | 上标 |
| `~下标~` | 下标 |
| `\*` | 转义：输出字面字符 |

## 语义块

`:: 名称` 开头，属性行与正文之间用 `---` 分隔；没有 `---` 时整段都是正文。

```
:: figure
src: plot.png
alt: 示意图
caption: 系统架构
id: fig-arch
width: 12cm
---
可选的图内说明文字
```

| 块 | 属性 | 说明 |
|----|------|------|
| `:: figure` | `src` `alt` `caption` `id` `width` | 图片，自动编号 |
| `:: code <语言>` | `caption` `id` | 代码清单，自动编号 |
| `:: quote` | `source` `caption` `id` | 引用块，内容可含块级语法 |
| `:: note` / `warning` / `tip` / `caution` / `important` | `title` `caption` `id` | 提示框 |
| `:: math` | `caption` `id` | 独立公式（display），自动编号 |
| `:: definitions` | — | 定义列表（`术语: 定义`） |
| `:: bibliography` | `title` `id` | 参考文献，`key: 条目` |

带 `caption` 或 `id` 的块会占用对应计数器（图 / 表 / 清单 / 公式）。

## 表格

```
| 名称 | 数量 | 备注 |
| < | ^ | > |
| 左对齐 | 居中 | 右对齐 |
```

第二行是**对齐行**（`<` 左、`^` 居中、`>` 右），可省略。表格使用 booktabs 三条横线，
跨页时重复表头。单元格内可用行内语法（含公式）。

对齐行里可以同时写列宽（Typst 语义）：

```
| 名称 | 数量 | 备注 |
| <2cm | ^30% | >2fr |
| 左对齐 | 居中 | 右对齐 |
```

| 写法 | 含义 |
|------|------|
| `<2cm` | 绝对长度（`pt` `mm` `cm` `in` `em` `bp`） |
| `^30%` | 占版心宽度的百分比 |
| `>2fr` | 剩余空间的分配权重；纯数字（`<1`）同样按 `fr` 处理 |
| `<` | 不指定宽度，按该列内容的自然宽度分配 |

规则：显式列宽先满足；有 `fr` 列时，auto 列保持自然宽度、剩余空间由 `fr` 列按权重
瓜分；没有任何 `fr` 列时整块版心按自然宽度比例填满。最小宽度取最宽不可断行单词
（CJK 按单个字形），总宽超出版心时按比例压缩。HTML 后端用 `<colgroup>` 表达显式列宽。

## 页面指令

| 指令 | 作用 |
|------|------|
| `%% pagebreak` | 强制分页 |
| `%% columnbreak` / `%% column-break` | 强制换栏（单栏时等价于分页；RTF 输出 `\page`） |
| `%% toc` | 插入目录 |
| `%% rule` / `%% hr` | 水平分隔线 |
| `%% include path` | 引入另一个 `.zt` 文件（相对当前文件） |

## 脚本

```
@{
let name = "Ztype"
}

当前项目是 @(name)。
```

脚本块只做变量定义；`@(name)` 在渲染时求值。

## 注释

```
; 行注释

;{
块注释
}
```

## 智能排版

默认开启（可用元数据 `smart: false` 关闭）：

| 输入 | 输出 |
|------|------|
| `"引号"` | `“引号”` |
| `don't` | `don’t` |
| `--` | `–`（en dash） |
| `---` | `—`（em dash） |
| `...` | `…` |
| `(c)` `(r)` `(tm)` `(p)` | `©` `®` `™` `℗` |
| `+-` `/-` `*-` `->` | `±` `÷` `×` `→` |

详见 [typography.md](typography.md)。
